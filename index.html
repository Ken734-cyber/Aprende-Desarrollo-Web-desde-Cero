Módulo 1: Lenguaje de Marcado (HTML5)

HTML es la columna vertebral que define la estructura y el contenido de la web.

1. Estructura Semántica Recomendada

Aprende a usar etiquetas con significado para mejorar la accesibilidad y el SEO:

  • <header>: Cabeceras del sitio o secciones.
  • <nav>: Barras de navegación con enlaces.
  • <main>: Contenido principal único de la página.
  • <article>: Bloques de contenido autónomos (tarjetas, noticias).
  • <footer>: Pie de página con créditos e información legal.

Módulo 3: Lógica e Interacción (JavaScript)

JavaScript le permite a tu sitio responder a las acciones del usuario en tiempo real.

Conceptos Básicos de JS para Empezar

  • Variables (const / let): Contenedores para guardar datos (textos, números, estados).
  • DOM (Document Object Model): La representación en memoria de tu HTML que JS puede modificar.
  • Eventos (addEventListener): Escuchadores que detectan clics, pulsaciones de teclas o envíos de formulario.
  • Funciones: Bloques de código reutilizables que ejecutan tareas específicas.
